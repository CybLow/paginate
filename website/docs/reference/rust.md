# Rust API reference

The Rust core, **`paginate-core`**, is documented on docs.rs — the canonical,
auto-published Rust API host:

➡️ **[docs.rs/paginate-core](https://docs.rs/paginate-core)**

`paginate-core` is the shared engine. The Python (`pypaginate`) and TypeScript
(`@cyblow/paginate`) packages you install are thin wrappers over it — so the engine's
behavior is documented once here, while each package's own surface lives in its
language reference (TypeScript on the left; Python alongside it). For *how to use*
the packages, see the [Guides](/getting-started/installation).
