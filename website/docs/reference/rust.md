# Rust API reference

The Rust core, **`paginate-core`**, is documented on docs.rs — the canonical,
auto-published Rust API host:

➡️ **[docs.rs/paginate-core](https://docs.rs/paginate-core)**

## The three references

The formal API surface is generated, one section per language:

| Language | Reference | Generated by |
|---|---|---|
| **Rust** | [docs.rs/paginate-core](https://docs.rs/paginate-core) | rustdoc |
| **TypeScript** | the *TypeScript* pages in this section | [TypeDoc](https://typedoc.org/) from `ts/src` |
| **Python** | the *Python* pages in this section | [pydoc-markdown](https://niklasrosenstein.github.io/pydoc-markdown/) from the `pypaginate` docstrings |

`paginate-core` is the shared engine; the Python (`pypaginate`) and TypeScript
(`@cyblow/paginate`) packages you install are thin wrappers over it. For *how to use*
the packages, see the language guides — [Python](../python/installation),
[TypeScript](../typescript/installation) — and the [Rust core](../rust/overview)
section for embedding the engine directly.
